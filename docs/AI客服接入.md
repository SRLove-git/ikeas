# NOVA AI 客服

右下角客服浮窗沿用 `POST /api/v1/chat/messages`，现在由本地 AI 客服项目回答。
支持可选关联订单号；前端通过统一 API 客户端携带登录令牌，并支持原有令牌刷新。
请求支持可选 UUID `conversationId`，用于按应用和认证用户隔离的短期话题记忆。FAQ 每轮发送当前候选，由 AI 结合中英文关键词和上轮话题筛选，旧回复不作为新事实。

后端设置 `NOVA_AI_URL`（本地联合启动 `http://127.0.0.1:18000`）及 `NOVA_AI_SECRET`。
密钥须与 AI 服务的 `AI_BUZUD_INTEGRATION_SECRET` 相同，不得与 OMS 使用同一密钥或进入浏览器构建。

FAQ 仍来自现有客服知识库；查询订单复用 `OrderService.get` 的用户归属校验。
模型只接收订单号、状态、金额与币种，不接收姓名、联系方式、地址或备注。
回复保留 `reply`，附带 `citations`、`requiresHuman`、`degraded`。
模型不可用会明确提示；需要人工时提供原有客服工单入口。聊天记录继续保存到原表。

本机联合启动：在 `/Users/yangyongze/Documents/ChatGPT/ai客服` 执行
`.venv/bin/python scripts/run_local_support_integration.py`。
完整构建与验收步骤在 AI 客服项目 `docs/LOCAL_SUPPORT_INTEGRATION.md`。
此接入未修改生产配置，也未将离线 LoRA 训练候选切为在线模型。

## 商品目录问答

客服每轮从完整商品目录中挑选与问题相关的商品，随签名请求交给 AI；AI 不直连商城数据库，也不缓存旧价格或库存。

- 匹配范围：商品名称、型号/规格、商品类型、类目、导航别名和商品页上下文。用户只输入“这个/这款”时，浮窗会把当前商品页 slug 一并提交。
- 商品证据：名称、编号、类目、售价（已接入 OMS 时优先使用 OMS 同步价）、规格、适用人群、用法、注意事项、包装、商品页链接和库存。
- 库存：存在 OMS SKU 映射时，明确询问库存会实时读取 OMS 可售库存；读取失败退回最近快照；没有映射或 OMS 未启用时明确提示“实时库存未接入，以商品页和结算结果为准”，不会声称有货。
- 浏览/推荐：询问“有什么商品/推荐”时返回类目概览和全部商品页入口；价格、规格、对比和推荐只使用本轮证据，资料没有的字段不补全。
- 商品页链接会以可点击链接显示；引用前缀为 `catalog://buzud/{productId}` 或 `catalog://buzud/overview`。

价格与库存仍可能变化，回答统一以商品页和下单结算结果为准。优惠券不在本轮商品证据范围内，涉及优惠时客服仍引导到领券中心，不承诺折扣。

## 部署与配置

本次商品目录问答不需要新增密钥或环境变量。更新独立站后端 jar（`ChatController` 与 `SupportProductCatalog`）并把 AI 服务源码同步到 support-suite 的 `ai-src` 后重启对应容器即可。

要返回真实 OMS 库存，需要独立站后端启用 `BUZUD_OMS_ENABLED=true`，配置 OMS 接入参数，并为商品建立 `oms_sku_mapping`。未启用时客服仍可回答商品资料和价格，但会明确标注实时库存未接入。

### 按需求反推商品

商品匹配除名称、型号和类目外，还会读取商品的适用人群/说明文本，因此中文需求可以反推英文商品名。例如“血糖高，想买个在家测血糖的”会匹配 `GlucoInsight`/`Safe AQ UG` 等血糖监测套装，而不是只返回 CGMS 或试纸；“老人长期吸氧”会匹配制氧机，“听力不好”会匹配助听器。

- 设备类需求（买、推荐、家用、测、监测等）会优先展示主机，电源线、袖带、试纸等配件/耗材降权；只有用户明确问配件、耗材、替换件时才优先配件。
- 目录中没有的品类会明确说明没有，并给出全部商品页入口，不虚构商品。
- 商品的屏幕大小、操作难易等资料未提供的属性不会被推断；客服会说明资料不足，并建议看商品页或咨询人工。

### 聊天记录保持

客服浮窗会把当前标签页最近 50 条消息、`conversationId` 和展开状态保存在 `sessionStorage`：

- 页面跳转、加购、筛选、切换商品等操作不会清空聊天记录；
- 刷新页面后仍恢复原对话和原 `conversationId`，不会生成新会话；
- 关闭标签页后清除，符合会话级隐私预期；
- 存储不可用（隐私模式等）时自动退回内存状态，不影响聊天。

如果需要跨设备或跨浏览器会话的历史，需要再接服务端历史接口；当前保持的是同一标签页内的会话。

### 商品购买链接

客服回答会额外返回 `products` 数组，每项包含商品 `id`、名称、`slug`、价格、图片和商品页 `url`：

```json
{
  "reply": "预算内可以看这款……",
  "products": [
    {
      "id": "8885020711097",
      "name": "BUZUD Blood Pressure Monitor 30S",
      "slug": "buzud-blood-pressure-monitor-30s-8885020711097",
      "price": 78,
      "image": "https://...png",
      "url": "/zh/p/buzud-blood-pressure-monitor-30s-8885020711097/"
    }
  ]
}
```

- 后端只为本轮签名证据中、且回答确实提到的商品生成链接：回答里出现商品页链接、完整商品名或该商品价格都会命中。
- “没有黄疸仪”这类否定回答不会附带无关商品卡片。
- 前端在机器人消息下渲染商品卡片，显示图片、名称、价格和「去购买」按钮；点击进入商品页，可正常加入购物袋。
- 商品页链接和卡片都会随聊天记录保存在 `sessionStorage`，刷新/跳转后仍然可用。
